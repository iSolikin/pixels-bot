# Pixels Bot

**Прототип браузерной автоматизации для Pixels.** Python и Playwright используются для управления действиями через браузер.

## Что уже исследовано

- Подход с управлением браузером и кликами через Playwright.
- Конфигурация локального запуска и проверка координат действий.
- Возможность наблюдать за процессом в открытом браузере.

**Статус: прототип.** Состав поддерживаемых сценариев и готовность к использованию нужно уточнять перед подключением.
