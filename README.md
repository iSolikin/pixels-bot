# Pixels Bot

Исследовательский проект по автоматизации действий в Pixels через Python и Playwright. Работа идёт в видимом браузере, поэтому каждый шаг можно наблюдать и проверять.

Сейчас это **прототип**: в нём проработаны управление браузером, клики и настройка сценариев под конкретные действия. Готовность нужной вам функции обсудим до подключения.
